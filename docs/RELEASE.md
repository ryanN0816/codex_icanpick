# 앱인토스 출시 준비

## 현재 확인한 범위

웹 개발 서버, 모바일·데스크톱 Chromium의 주요 사용자 흐름, 프로덕션 웹 빌드, 앱인토스 CLI의 `.ait` 패키징을 검증했습니다. 토스 앱 내부 동작, 콘솔 등록, 업로드, 심사 및 공개 출시는 아직 검증하거나 실행하지 않았습니다.

## 서비스 소개 초안

- 이름: 골라줘
- 한 줄 소개: 고민은 줄이고, 하루는 가볍게.
- 설명: 점심 메뉴부터 주말 계획까지, 선택지를 적으면 하나를 같은 확률로 골라드립니다. 자주 하는 고민은 템플릿으로 시작하고, 최근 선택 기록을 기기에서 확인할 수 있습니다.
- 데이터 처리: 고민의 제목, 선택지 초안과 최근 20개 결과를 기기 내 브라우저 저장소에 보관합니다. 작성 중인 초안은 '새로 시작하기', 결과 기록은 '기록 모두 지우기'로 삭제할 수 있습니다. 별도 서버 전송, 로그인, 광고 및 분석 SDK는 현재 구현하지 않았습니다. 콘솔에 제출할 개인정보 관련 문서는 실제 출시 구성에 맞춰 작성해야 합니다.

## 출시 전에 필요한 작업

1. 앱인토스 콘솔에서 앱을 등록하고 `apps-in-toss.config.ts`의 `appName`을 등록 이름과 일치시킵니다. 현재 `icanpick`은 개발용 이름입니다.
2. 앱 아이콘, 서비스 정보와 지원 연락처를 준비하고 최신 앱인토스 디자인·운영 정책을 확인합니다. 애플 스타일을 참고한 현재 화면의 토스 심사 적합성은 별도로 확인해야 합니다.
3. `npm run toss:build`로 등록 이름에 맞는 `.ait` 파일을 재생성합니다. 업로드는 별도 배포 권한으로 진행해야 하며 비밀 키를 저장소에 넣지 않습니다.
4. 토스의 테스트 환경에서 Android와 iOS 실기기로 입력, 결과 확정, 다시 고르기, 키보드, 뒤로가기, 재진입 시 초안·기록 보존을 확인합니다. 특히 WebView 저장소 수명은 브라우저 테스트만으로 보장할 수 없습니다.
5. 검증 후 앱인토스 심사를 진행합니다. 클라우드 개발 환경 게시와 앱인토스 앱 출시는 서로 다른 작업입니다.

## 로컬 검증 명령

```sh
npm test
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
npm run toss:build
```

시스템 Chromium이 없는 환경에서는 Playwright 브라우저 설치 후 환경 변수 없이 실행합니다.
