# 앱인토스 콘솔 등록 자료

아직 콘솔 등록 전입니다. 아래 값은 입력용 초안이며 실제 등록·승인된 정보가 아닙니다. 콘솔의 최신 필드, 글자 수와 이미지 요구사항에 맞춰 조정하세요.

| 항목 | 입력용 초안 |
| --- | --- |
| 서비스 이름 | 골라줘 |
| 영문 앱 식별자(appName) | icanpick — 사용 가능 여부를 콘솔에서 확인 |
| 한 줄 소개 | 고민은 줄이고, 하루는 가볍게. |
| 설명 | 점심 메뉴부터 주말 계획까지, 선택이 어려울 때 골라줘를 만나보세요. 선택지를 적으면 하나를 같은 확률로 골라드립니다. 일상 고민 템플릿으로 빠르게 시작하고, 최근 선택 기록도 이 기기에서 확인할 수 있어요. |
| 주 색상 | #3276EF |
| 로그인 | 현재 구현하지 않음 |
| 권한 | 요청 권한 없음 |

## 아이콘

- 업로드용 초안: `assets/icanpick-icon-600.png` (600×600 PNG)
- 편집 원본 및 웹 파비콘: `public/icon.svg`
- 둥근 모서리나 외부 그림자 없이 정사각형으로 제작했습니다. 콘솔의 최신 규격에 맞는지 확인한 뒤 사용하세요.
- 아이콘 재생성: `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium node scripts/render-icon.mjs`

## 사용자가 정해야 하는 정보

운영 주체, 고객 지원 연락처, 실제 서비스 URL, 콘솔에서 요구하는 약관·개인정보 문서 정보는 임의로 만들지 않았습니다. 현재 앱 안의 ‘앱·개인정보 안내’는 기능과 저장 방식을 설명하는 화면이며, 사업자 정보 등이 들어간 정식 법적 문서를 대신하지 않습니다.

## 등록 후 이어갈 작업

1. 등록 완료된 영문 앱 식별자만 채팅에 알려주세요. API 키나 배포 토큰은 채팅이나 저장소에 넣지 마세요.
2. 식별자를 `apps-in-toss.config.ts`에 반영하고 `npm run toss:build`로 해당 이름의 `.ait`를 생성합니다.
3. 배포는 별도 명시적 요청과 인증이 필요한 단계입니다. 인증은 앱인토스가 지원하는 보안 경로에서 설정합니다.
4. 테스트 배포 후 토스 앱에서 Android/iOS 사용자 흐름을 확인합니다. 검증 항목은 [출시 준비](RELEASE.md)를 참고하세요.
