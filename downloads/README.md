# 앱인토스 패키지

[icanpickforyou.ait 다운로드](https://github.com/ryanN0816/codex_icanpick/raw/refs/heads/main/downloads/icanpickforyou.ait)

현재 `appName: icanpickforyou`으로 생성된 개발용 패키지입니다. 앱인토스 콘솔에 등록된 영문 앱 식별자가 다르면 설정을 맞추고 다시 빌드해야 합니다. 토스 앱 안에서의 실기기 검증과 공개 배포는 아직 진행하지 않았습니다.

소스 변경 후 `npm run toss:build`로 다시 생성한 루트의 `icanpickforyou.ait`를 이 폴더에 복사해야 최신 상태가 반영됩니다.
